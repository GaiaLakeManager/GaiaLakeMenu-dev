Accepting Orders

When this is off, guests see a "message or email us to order" banner instead of the menu's ordering buttons and hours.
Date for each item. When on, every item in the order window has its own "Please select date" picker. When off, the guest picks one date for the whole order. Guests always see just one of the two.
Serving times are not shown to guests (they can write a special time in the order Note); they are only used to refuse a meal that has already passed today. Categories set to Breakfast, Lunch or Dinner only are always served at that meal's time: the guest picks just the date and sees e.g. "For Lunch".
Times are in Sri Lanka time (Asia/Colombo), regardless of a guest's own timezone. After the cutoff, guests can no longer choose today as the dining date (tomorrow onward still works). The dining time picker only allows Kitchen Opens through Latest dining time; anything outside that, guests are asked to write in the order Note instead. An order sent while the kitchen is closed still goes through, but the alert to you is marked so staff know it wasn't seen live.

Rooms / Villas / Cottages

Guests pick from this list when ordering. Type each name exactly as it should appear (e.g. Room 1, Lotus Villa) — it is shown as entered everywhere. Separate several with commas (up to 30 characters each). Change the field name above (Room, Villa, Cottage…) whenever your accommodation changes.

Group / Bulk-order Labels

Added to the guest Room dropdown alongside Room Numbers. Selecting one of these shows the Group Selection Policy reminder on the order review screen. Add or rename these anytime — no code change needed.
